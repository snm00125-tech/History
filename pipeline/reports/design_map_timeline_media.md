# 설계: 지도 · 연도별 도식 · 사진/인물 배경 (2026-11-22)

지금 앱은 「날짜 → 그날 기록」 한 길만 있다. 같은 247만 건을 **어디서(지도)**, **언제 몰렸나(연도 도식)**, **누구·무엇(사진·인물)** 세 방향에서 보게 만든다.
모든 화면은 지금처럼 정적 사이트(미리 만든 JSON)로 만든다. 실시간 AI 호출 없음.

## 1. 연도별 도식 — `/timeline/` (외부 자료 없이 바로 가능)

### 화면
```
 기원전 706 ───────────────────────────────────────────────── 2008
 [왕조 띠]  고구려 ████████  백제 ██████  신라 ███████████ │고려 ██████│조선 ████████████│대한제국│일제│대한민국
 [왕 막대]  (확대하면 왕별 재위 막대, 누르면 그 왕 첫 달로)
 [사건 ★]   ★살수대첩  ★귀주대첩  ★훈민정음  ★임진왜란 …   (주요 사건 119 + 국편 연표 중요도1 363)
 [기록량]   ▁▂▃▅▇█▇▅▃▂  연도별 기사 수 막대 (자료별 색: 실록·승정원일기·비변사등록·고려사…)
 [분류]     전쟁·군사 / 외교 / 자연현상 … 고르면 그 분류만 막대로
```
- 끌기·확대(마우스 휠/두 손가락): 2,700년 → 한 왕 재위 → 한 해(달별 막대)까지.
- 막대를 누르면 그해 첫 달 `/view/`로.
- 「같은 해 비교」: 삼국은 세 줄(고구려·백제·신라)을 나란히.
- 연도 막대 아래 그해 국편 연표 제목 몇 줄.

### 데이터 (내보내기에 추가, 작음)
- `timeline.json`: 연도별 {자료별 기사 수, 분류별 기사 수} — 약 2,700년 × 20칸, 수백 KB.
- `dynasties.json`: 왕조·왕의 재위 범위. 조선은 지금 `kings.json`, 고려·삼국은 기사 왕력(regnal_src)의 첫·끝 날짜에서 만든다(원자료 근거).
  대한제국·일제강점기·대한민국 구간은 날짜가 분명한 사실(1897-10-12, 1910-08-29, 1945-08-15, 1948-08-15)로 고정 표에 둔다.
- 사건: 기존 `events.json` + 연표 중요도 1.

### 작업량
반나절~하루. 그림은 SVG로 직접(라이브러리 추가 최소).

## 2. 지도 — `/map/`

### 화면
- 바탕 지도: Leaflet(npm) + 오픈스트리트맵 타일(사용자 브라우저가 직접 받음, 개인 사용 수준이면 규정 안).
- **지명 언급 지도**: 기간(연도 막대로 고름)·분류·자료를 고르면 그 기간 기사에 나온 지명을 원 크기(언급 수)로 표시.
  원을 누르면 그 지명이 나온 기사 목록(날짜순) → 누르면 그날 화면.
- **사건 지도**: 주요 사건(전투·천도·민란 등)에 장소를 붙여 ★로. 연도 막대를 움직이면 그때 사건만.
- **국가유산 층**(사진 자료와 함께, 3절): 궁궐·성곽·사찰·왕릉 위치와 사진.
- 그날 화면에도 작은 지도: 그날 기사에 나온 지명들.

### 지명 → 좌표 (가장 큰 일)
- 실록·고려사 원문에는 국편 지명 색인이 이미 있다: **언급 548,094번, 서로 다른 지명 30,753개.**
  위에서 1,000개만 좌표를 붙여도 언급의 **77.6%**, 3,000개면 **88.7%**를 덮는다.
- 좌표 출처(추측 금지, 출처를 칸에 남김):
  1. **위키데이터**: 조선 군현·산성·전투지 등에 좌표와 한자 이름이 있다. 한자 이름으로 맞춘다.
  2. 국편 **역사지리**(15053641, 받아 둠): 옛 지명 → 1914년·현재 행정구역 이름 대응(리 단위 28,087개). 좌표는 없어서, 현재 행정구역 좌표(위키데이터)와 이어 붙인다.
  3. 도(道)·나라 이름(慶尙道, 倭, 遼東 등)은 넓은 지역이라 점 대신 구역 이름표로만.
- 같은 이름이 여러 곳인 경우(예: 같은 군 이름) → 기사 앞뒤 도 이름으로 고르고, 못 고르면 지도에서 빼고 목록에만.
- 옛 국경선(삼국 영역 등)은 믿을 만한 공개 자료를 아직 못 찾았다 → 첫 판에서는 그리지 않는다(지어내지 않음).

### 데이터
- `geo/places.json`(지명·좌표·출처), `geo/<연대>.json`(시기별 지명 언급 수·기사 문서 번호). 파일 수 수십 개.

### 작업량
지도 화면 1일 + 좌표 붙이기 1~2일(위키데이터 접속 필요).

## 3. 사진 · 인물 배경

### 3-1. 인물 화면 넓히기 (`/person/`)
- 지금: 실록 인물 115,859명(국편 부가정보: 이름·본관·관직 기록·나오는 기사).
- 더할 것:
  - **한국역대인명정보**(한국학중앙연구원 15052748, 받아 둠): 27,035명의 자·호·생몰년·본관. 이름+생몰년으로 실록 인물과 잇는다.
  - **약력·배경**: 한국어 위키백과 요약(CC BY-SA, 출처·저작자 표시) — 이름+생몰년으로 맞는 문서만. 「위키백과 요약」으로 따로 표시하고, 이 앱이 쓴 해설과 섞지 않는다.
  - **초상·사진**: 위키데이터 「이미지」 항목 → 위키미디어 공용(대개 퍼블릭 도메인 초상화). 이미지 파일은 저장하지 않고 공용 서버 주소로 보여 주며, 그림 아래 출처·저작권 표시.
  - **생애 연표**: 그 사람이 나오는 기사 수를 연도별 막대로 + 관직 기록을 그 위에.
  - **관계**: 같은 기사에 자주 함께 나오는 인물 10명(원문 색인으로 계산, 추측 없음).
- 인물 대상: 언급이 많은 순 상위 약 5,000명부터(나머지는 국편 정보만).

### 3-2. 유물·유적 사진
- **국가유산청 공개 API**(지정 유산 목록·위치·사진, 키 없이 쓰는 API가 있음): 궁궐·왕릉·성곽·사찰 → 지도 층 + 관련 인물·사건과 연결(예: 이순신 → 현충사·한산도).
- **국립중앙박물관 e뮤지엄 API**(소장품 사진·시대): 「이 시대의 유물」을 연도 도식·그날 화면 옆에. 공공데이터포털 인증키 필요.
- 사진은 원 기관 주소로 보여 주고(저장 안 함), 출처·이용조건(공공누리 등)을 함께 표시.

### 3-3. 사건 화면 (`/event/?id=`)
- 주요 사건마다: 관련 실록 기사, 장소(지도), 관련 인물, 관련 유물·유적 사진, 위키백과 요약(출처 표시).

## 5. 필요한 것 (사용자 결정)
1. **네트워크 허용**(지금 이 작업 환경은 아래 주소가 막혀 있음. 사진을 보는 사용자 브라우저와는 상관없음, 자료를 모으는 단계에만 필요):
   `www.wikidata.org`, `ko.wikipedia.org`, `commons.wikimedia.org`(지도 좌표·인물 요약·사진 정보), `apis.data.go.kr`(e뮤지엄 등), 국가유산청 API 주소.
2. **공공데이터포털 인증키**(e뮤지엄용) — 쓰려면. 키는 주소 뒤에 붙는 방식이라 환경 변수로 넣어야 한다.
3. 순서: 추천 = ① 연도 도식(바로 가능) → ② 지도 → ③ 인물 배경·사진.
